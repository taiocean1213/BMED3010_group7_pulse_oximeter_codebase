# Security Policy

## Supported Versions

This project is under active development. Security fixes, safety-related fixes,
and dependency updates should target the `main` branch unless maintainers note
otherwise.

## Reporting a Vulnerability

Please do not open public issues for potential security or safety problems.

Instead, report issues privately through GitHub Security Advisories or contact
the maintainer directly if a private reporting channel is available.

Please include:
- affected component(s)
- reproduction steps
- potential impact
- logs, traces, or screenshots if relevant
- whether physical hardware access is required

You should expect an acknowledgment within 7 days.

## Scope Notes

Because this project interfaces with biomedical-style sensing hardware,
reports involving signal integrity, incorrect health readings, unsafe hardware
behavior, or privacy-sensitive telemetry should be treated as high priority.
